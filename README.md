# Movie Review Database

React + Vite frontend with dummy review analytics and an AWS-ready backend direction.

## Live site

https://wats3082.github.io/Project-Movie-Reviews-Database/

## AWS backend direction

1. API Gateway + Lambda review API
2. DynamoDB for movie and review entities
3. S3 for assets and batch exports
4. EventBridge/SQS for moderation and async pipelines
